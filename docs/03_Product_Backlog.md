# Product Backlog — «СпортТовары»

Роли: **покупатель**, **продавец-консультант**, **управляющий магазином**.
Шкала оценки — числа Фибоначчи (1, 2, 3, 5, 8).

## Высокий приоритет

### US-1. Товары с низким остатком
**Как** управляющий, **я хочу** видеть товары, которых осталось 3 шт. и меньше, **чтобы** вовремя сделать дозаказ.
**Критерии приёмки:**
- учитывается сумма остатков по всем размерам;
- пустой каталог даёт пустой список;
- порог по умолчанию 3, его можно передать параметром.
**Оценка:** 2 story points
**Приоритет:** Высокий

### US-2. Расширенный поиск
**Как** покупатель, **я хочу** искать по части названия, категории и диапазону цены одновременно, **чтобы** быстро найти подходящий товар.
**Критерии приёмки:**
- поиск без учёта регистра;
- любой фильтр можно не указывать (`None`);
- границы цены включаются.
**Оценка:** 3 story points
**Приоритет:** Высокий

### US-3. Управление корзиной
**Как** покупатель, **я хочу** менять количество и удалять позиции, **чтобы** собрать нужный заказ.
**Критерии приёмки:**
- нельзя положить больше, чем есть на складе;
- количество 0 удаляет позицию;
- несуществующий размер — понятное сообщение.
**Оценка:** 3 story points
**Приоритет:** Высокий

### US-4. Оформление и сохранение заказа
**Как** продавец, **я хочу** оформить заказ из корзины и сохранить его в файл, **чтобы** заказы не терялись после закрытия программы.
**Критерии приёмки:**
- заказ содержит номер, дату, клиента, позиции и сумму;
- заказы пишутся в `orders.json` в UTF-8 и читаются обратно без потерь.
**Оценка:** 5 story points
**Приоритет:** Высокий

## Средний приоритет

### US-5. Количество товаров по категориям
**Как** управляющий, **я хочу** видеть, сколько наименований в каждой категории, **чтобы** планировать ассортимент.
**Критерии приёмки:** результат — словарь `{категория: число}`; пустой каталог — `{}`.
**Оценка:** 1 story point
**Приоритет:** Средний

### US-6. Средняя цена
**Как** управляющий, **я хочу** знать среднюю цену товаров (всего каталога или категории), **чтобы** сравнивать с конкурентами.
**Критерии приёмки:** округление до копеек; для пустого списка — 0.
**Оценка:** 1 story point
**Приоритет:** Средний

### US-7. Итог по позициям
**Как** продавец, **я хочу** видеть сумму товаров с учётом количества, **чтобы** назвать покупателю цену без скидок.
**Критерии приёмки:** сумма `price × quantity`; пустой список — 0.
**Оценка:** 1 story point
**Приоритет:** Средний

## Низкий приоритет

### US-8. Выручка и средний чек
**Как** управляющий, **я хочу** видеть выручку и средний чек по сохранённым заказам, **чтобы** оценивать продажи.
**Критерии приёмки:** считаются все заказы из файла; нет заказов — 0.
**Оценка:** 2 story points
**Приоритет:** Низкий

### US-9. Хит продаж
**Как** управляющий, **я хочу** знать самый продаваемый товар, **чтобы** держать его в запасе.
**Критерии приёмки:** сравнение по числу проданных штук; нет заказов — `None`.
**Оценка:** 2 story points
**Приоритет:** Низкий

### US-10. Консольное меню
**Как** продавец, **я хочу** работать через нумерованное меню, **чтобы** не помнить имена функций.
**Критерии приёмки:** все сценарии доступны из меню, неверный ввод не завершает программу.
**Оценка:** 3 story points
**Приоритет:** Низкий
