# Руководство пользователя

## Запуск
Откройте терминал в папке `SportShop` и выполните `python main.py`. Появится меню:
```
──────── СпортТовары ────────
 1. Каталог
 2. Поиск товара
 3. Товары с низким остатком
 4. Добавить в корзину
 5. Корзина: показать / изменить / удалить
 6. Оформить заказ
 7. Аналитика продаж
 8. История заказов
 0. Выход
```
Введите номер пункта и нажмите Enter. Неверный ввод не завершает программу —
появится сообщение «Нет такого пункта меню» или «Неверный ввод».

## 1. Просмотр каталога
**Команда:** `1`.
**Результат:** таблица: ID, название, категория, цена, доступные размеры в виде
`размер:остаток`.
```
   1. Кроссовки беговые Pulse        Бег         5990.00 ₽  [40:3, 41:4, 42:2, 43:1]
   3. Мяч футбольный Pro             Футбол      2790.00 ₽  [5:12]
```

## 2. Поиск товара
**Команда:** `2`, затем по запросу: часть названия, категория, цена от, цена до.
Пустой ввод (Enter) — фильтр не применяется.
**Пример:** `кроссовки`, Enter, `5000`, `9000` →
```
   1. Кроссовки беговые Pulse        Бег         5990.00 ₽  [...]
  10. Кроссовки баскетбольные Jump   Баскетбол   8490.00 ₽  [42:1, 43:2]
```

## 3. Товары с низким остатком
**Команда:** `3`. **Результат:** `⚠ Палатка Dome 2 — осталось 2 шт.` и т. д.

## 4. Добавление в корзину
**Команда:** `4`, затем ID товара, размер, количество.
**Пример:** `1`, `42`, `2` → `«Кроссовки беговые Pulse» (р. 42) × 2 в корзине`.
Сообщения об ошибках: `Товар 99 не найден`, `Размер 44 отсутствует…`,
`На складе только 4 шт. размера 41`.

## 5. Работа с корзиной
**Команда:** `5` — список позиций и сумма со скидкой. Далее:
`и` — изменить количество (номер позиции, новое количество; `0` удаляет),
`у` — удалить позицию, Enter — назад.

## 6. Оформление заказа
**Команда:** `6`, затем имя клиента. **Результат:** чек заказа, остатки
уменьшаются, заказ сохраняется в `data/orders.json`, каталог — в `data/products.json`.
```
Заказ SP-20261016-163621788 от 2026-10-16 16:36, клиент: Смирнова Ольга
  Палатка Dome 2                 р.2    1 × 8990.00
  Коврик для йоги                р.183  2 × 1890.00
  ИТОГО: 11493.00 руб.
```

## 7. Аналитика продаж
**Команда:** `7`. **Результат:** число заказов, выручка, средний чек, хит
продаж, количество наименований по категориям.

## 8. Сохранение и загрузка заказов
Заказы сохраняются автоматически при оформлении (п. 6) и загружаются при
запуске. **Команда:** `8` — перечитать файл и показать историю.

## Выход
**Команда:** `0` → `До свидания!`.

## Частые вопросы
| Ситуация | Что делать |
|----------|-----------|
| «Корзина пуста или не указано имя» | добавьте товар (п. 4) и введите имя |
| нужно вернуть исходный каталог | `git checkout data/products.json` |
| удалить историю заказов | удалите файл `data/orders.json` |
