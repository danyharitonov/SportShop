# Ретроспектива спринта 1

## Что прошло хорошо
- Маленькие задачи по 20–40 минут — каждая заканчивалась коммитом.
- WIP-лимит 2 не дал «распылиться»: одновременно делались максимум 2 истории.
- Формат «US-N: описание» в коммитах позволяет найти изменения по истории.

## Что можно улучшить
- US-4 оценена в 5 SP и заняла больше всего времени — крупные истории нужно резать мельче.
- Функции проверялись только ручным запуском — нет автотестов.
- Не все задачи спринта закрыты (US-1, US-7).

## Что попробуем в следующем спринте
1. Каждая новая функция — в своей feature-ветке (Git Flow).
2. Для каждой истории сразу писать хотя бы один тест `unittest`.
3. Планировать не более 8 SP на занятие.
