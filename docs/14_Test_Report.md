# Отчёт о тестировании (ПР №8)

Команда: `python -m unittest discover -s tests -v`

| Класс тестов | Что проверяется | Тестов |
|--------------|-----------------|--------|
| `TestGetLowStock` | пустой каталог, нет низких остатков, сумма по размерам, граница 3, свой порог | 5 |
| `TestSearchAdvanced` | название без регистра, категория, диапазон цены (включительно), все фильтры, пустой результат | 5 |
| `TestTotalSum` | пустой список, с количеством, без поля quantity | 3 |
| `TestAddToCart` | несуществующий размер, неизвестный товар, успех, повторное добавление, больше остатка, деление на ноль | 6 |
| `TestCartOperations` | удаление, изменение количества, больше остатка, обнуление, отрицательное, сумма со скидкой / без / пустая | 8 |
| `TestOrdersAndAnalytics` | создание заказа, пустая корзина, JSON туда-обратно, нет файла, категории и средняя цена | 5 |
| **Итого** | | **32** |

## Результаты
- Первый прогон: **30 из 32** прошли, 2 упали
  (`test_update_to_zero_removes_item`, `test_negative_quantity_rejected`).
- После исправления `update_quantity`: **32 из 32 — OK**.

## Найденные и исправленные ошибки
| № | Функция | Ошибка | Исправление |
|---|---------|--------|-------------|
| 1 | `update_quantity` | количество 0 оставляло «пустую» позицию в корзине | 0 удаляет позицию |
| 2 | `update_quantity` | принималось отрицательное количество | возвращается `False` с сообщением |
| 3 | собственный тест | в `test_by_price_range_inclusive` ожидалось `{1, 4}`, хотя бутсы за 4 500 ₽ попадают в диапазон | исправлено ожидание на `{1, 3, 4}` |

## Функции без тестов
- `show_catalog`, `highlight_low_stock` — только печать/форматирование, проверяются визуально;
- `find_product`, `_position` — вспомогательные, покрыты косвенно через корзину.
