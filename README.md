# СпортТовары — система управления магазином

Консольное приложение для небольшого магазина спортивных товаров: каталог с
остатками по размерам, поиск, корзина со скидкой, оформление заказов с
сохранением в JSON и аналитика продаж. Учебный проект по УП.02
(практические работы №5–10); материалы ПР №1–4 (вариант «Туроператор») —
в папке `practice_1-4/`.

Автор: Харитонов Даниил Сергеевич, группа 3ИП-7-24
Репозиторий: [ссылка на репозиторий]

## Возможности
- каталог из 10 товаров в 5 категориях, остатки по размерам;
- комбинированный поиск: название, категория, диапазон цены;
- список товаров с низким остатком (≤ 3 шт.);
- корзина: добавление с проверкой остатка, изменение, удаление; скидка 10 % от 10 000 ₽;
- оформление заказа, списание остатков, сохранение `data/orders.json`;
- аналитика: выручка, средний чек, хит продаж, товары по категориям.

## Требования
- Python 3.10+ (только стандартная библиотека);
- SQLite не используется — данные хранятся в JSON.
